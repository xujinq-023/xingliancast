# 星联投屏 · 发码手册（发行方内部）

> ⚠️ `license-private.txt` 是签发私钥，**永远不要发给客户、不要放进安装包**。
> 它一旦泄露，任何人都能生成有效激活码。

## 一、客户发来机器码后，一条命令出码

```bat
MakeLicense.exe /machine E00C-2577-C37A /days 0
```

| 参数 | 含义 |
|---|---|
| `/machine <机器码>` | 客户软件「☰ → 正版注册」里显示的机器码 |
| `/days 0` | **永久授权** |
| `/days 365` | 一年授权（到期后需重新发码） |
| `/days 30` | 试用延长/短期授权 |

输出示例：

```
机器码 : E00C-2577-C37A
时长   : 永久
激活码 : XL1.AfvTVAE8wP____8BHYxJ4ODVN0oAu6mteFpJg2mrwWygxz2Pt2PNHw6plAE5h0OndgCzTB4tC75lhMoODqGdorq_8fra-zo6ySFKYg
长度   : 106 字符
```

把 **激活码整行** 发给客户，客户粘贴到「正版注册」窗口点「注册」即可。
（同时会写一份到 `last-license.txt`，方便复制）

## 二、客户怎么找到机器码

软件右上角 **☰ → 正版注册** → 「本机机器码」一栏，点一下可全选复制。

或者让客户运行诊断（不用开界面）：

```bat
ProjectorUi.exe --diag
```
会把机器码、授权状态、今日试用剩余秒数打印出来（同时写到 `%TEMP%\xl_diag.txt`）。

## 三、试用规则

- 未注册用户：**每天 5 分钟**投屏额度，按自然日重置
- 用完后再点「开始投屏」会弹「今日免费试用已用完」
- 注册后不再受限；永久授权没有到期日

## 四、常见问题

| 现象 | 原因 |
|---|---|
| 「激活码与本机机器码不匹配」 | 客户换了机器/重装系统，需要重新发码 |
| 「激活码无效（签名校验失败）」 | 复制时漏字符或换行，让客户重新整段复制 |
| 「激活码已过期」 | 发的是限时码，需续期 |
| 客户想换电脑 | 重新发一个对应新机器码的码即可（旧码在新机器上无效） |

## 五、密钥管理

| 文件 | 用途 | 注意 |
|---|---|---|
| `license-private.txt` | 签发私钥（X/Y/D） | **离线保管**，丢失后所有已发码仍有效，但无法再发新码（需重新生成密钥并更新客户端公钥） |
| `license-public.txt` | 公钥 | 已内置在 `ProjectorUi.exe` 源码 `License.PubX/PubY` |
| `signing\license-private.txt` | 私钥备份 | 与 `tools\` 下同一份 |

**建议**：私钥文件再加一层压缩包密码，或放到离线 U 盘，不要和代码一起提交到公开仓库。

# 附：图形界面版（推荐日常使用）

双击 **`MakeLicenseGui.exe`**（需与本目录的 `license-private.txt` 在一起）：

```
┌──────────────────────────────────────────┐
│  激活码生成器                              │
│  把客户发来的机器码粘进来，选时长…         │
│                                           │
│  客户机器码  [E00C-2577-C37A]  [粘贴] [用本机] │
│  授权时长    [永久 ▾]   [生成激活码]        │
│                                           │
│  激活码（点一下即可复制）                   │
│  ┌────────────────────────────────────┐  │
│  │ XL1.AfvTVAE8wP____8B0GQWRY18…      │  │
│  └────────────────────────────────────┘  │
│  [复制激活码]   已生成：…（106 字符）       │
└──────────────────────────────────────────┘
```

| 操作 | 说明 |
|---|---|
| **点一下激活码框** | 直接复制到剪贴板（最常用） |
| `粘贴` | 从剪贴板取机器码 |
| `用本机` | 填本机机器码（自己测试用） |
| 授权时长 | 永久 / 365 / 180 / 90 / 30 天 / 自定义 |

命令行版 `MakeLicense.exe` 仍然保留，适合做批处理脚本。
