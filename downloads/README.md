# 下载

安装包体积较大，不放在 git 仓库里，统一放在 **Releases**：

👉 **[最新版本](https://github.com/xujinq-023/xingliancast/releases/latest)**

| 文件 | 说明 |
|---|---|
| `XingLianCast-Setup-x.y.z.exe` | Windows 安装包（推荐，含防火墙规则） |
| `XingLianCast-Portable-x.y.z.zip` | 免安装便携版，解压即用 |
| `receiver-tv.apk` | 电视端 App（Android 7.0+） |

## 校验

每个 Release 页面会列出安装包的 **SHA256**，下载后可自行核对：

```powershell
Get-FileHash .\XingLianCast-Setup-1.0.47.exe -Algorithm SHA256
```
