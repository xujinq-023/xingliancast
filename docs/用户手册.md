# 星联投屏 · 用户手册

适用版本：**1.0.13**（电脑端 `XingLianCast.exe` / 电视端 `receiver-tv.apk`）

---

## 一、安装

### 电脑端

1. 双击 `XingLianCast-Setup-1.0.13.exe`
2. 出现「用户账户控制」→ 点**是**（安装到 `C:\Program Files\XingLianCast` 需要管理员权限）
   - 若点「否」也能装，只是会装到 `%LOCALAPPDATA%\Programs\XingLianCast`
3. 可选：创建桌面快捷方式 / 安装完成后立即启动
4. 点「安装」，约 20 秒完成

安装包会自动把代码签名证书装进系统，以后不会出现「未知发布者」提示。

### 电视端

方式一（U 盘）：把 `receiver-tv.apk` 拷到 U 盘 → 插电视 → 用电视的文件管理器安装（需允许「未知来源」）。

方式二（ADB）：

```bat
adb connect <电视IP>:5555
adb install -r receiver-tv.apk
```

## 二、首次运行

1. 电脑端启动后，Windows 防火墙会弹「是否允许访问网络」→ 必须选**允许**
   （选错了：控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙 → 勾选「星联投屏」）
2. 电视端打开「星联投屏」，屏幕显示：

```
            星联投屏
          等待电脑投屏…
  TV  →  QINL-370A   10.5.9.22:45690
  PC  →  未连接
```

3. 电脑端「接收端」下拉框会自动发现电视（约 1~2 秒），显示 `QINL-370A · 10.5.9.22`

> 搜不到？点「刷新」，或确认电脑与电视在同一路由器/同一网段。

## 三、投屏

| 控件 | 说明 |
|---|---|
| 显示器 | 多屏时选择要投的屏幕（默认主屏） |
| 分辨率 | 「原生分辨率」= 跟随屏幕；也可固定 1080p / 720p（节省带宽） |
| 帧率 | 默认 60；画面卡顿可降到 30 |
| 码率 | 默认 8000 kbps；WiFi 不稳建议 4000 |
| **开始投屏 / 停止投屏** | 投屏中按钮变绿并显示「投屏中」 |
| **传输声音：开/关** | 投屏中可随时切换，立即生效 |
| **自动恢复：开/关** | 断线后是否自动重连（默认开） |

下方指标卡实时显示：电脑帧率、编码耗时、网络流量、网络延迟、电视帧率、丢包等。

### 停止投屏

点「停止投屏」，或直接关闭电脑端窗口（会优雅通知电视断开）。

---

## 四、锁屏与隐私

电脑按 **Win+L** 锁屏后：

- 电视立即切到「电脑已锁屏」页面，**不再显示桌面内容**
- 页面显示电视与电脑的型号/IP，方便排查
- 电脑解锁后 1 秒内自动恢复投屏

> 这层保护在「自动恢复」关闭时同样生效。

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 电视搜不到电脑 | ① 同一路由器？② 防火墙放行？③ 电视端重开 App |
| 画面卡顿/花屏 | 码率降到 4000、帧率降到 30；优先用 5G WiFi 或有线 |
| 没有声音 | 确认「传输声音：开」；检查电脑是否静音 |
| 延迟大（操作不同步） | 看指标卡「网络延迟」；>500ms 说明链路差，换 5G/有线 |
| 投屏 5 分钟后自动停止 | 未注册，每天 5 分钟额度用完；注册后解除 |
| 提示「保存失败」 | 安全软件拦截写盘；程序会自动换位置保存，若仍失败请联系我们 |
| 换电脑后激活码无效 | 正常，需重新发码 |

## 七、卸载

控制面板 → 程序和功能 → 「星联投屏」→ 卸载；
或运行安装目录下的 `uninstall.exe`。

卸载会删除程序文件、快捷方式和注册信息，**保留**接收端 APK 和日志目录。
