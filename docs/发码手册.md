> 私钥一旦泄露，任何人都能生成有效激活码。

## 一、一条命令出码

工具在 `installer\tools\`，与 `license-private.txt` 放在同一目录。

### 图形版（日常用这个）

双击 `MakeLicenseGui.exe`：

```
客户机器码  [E00C-2577-C37A]   [粘贴] [用本机]
授权时长    [永久 ▾]           [生成激活码]

激活码（点一下即可复制）
┌────────────────────────────────────────┐
│ XL1.AfvTVAE8wP____8B0GQWRY18…          │
└────────────────────────────────────────┘
[复制激活码]        已生成：…（106 字符）
```

- **点一下激活码框**即复制到剪贴板
- `用本机` = 填入本机机器码（自己测试用）
- 时长可选：永久 / 365 / 180 / 90 / 30 天 / 自定义

### 命令行版（批处理用）

```bat
MakeLicense.exe /machine E00C-2577-C37A /days 0      :: 永久
MakeLicense.exe /machine E00C-2577-C37A /days 365    :: 一年
MakeLicense.exe /machine                            :: 打印本机机器码
MakeLicense.exe /keygen                             :: 重新生成密钥对（慎用！）
```

出码同时写入 `last-license.txt` 便于复制。

## 二、客户怎么找机器码

- 软件右上角 **☰ → 正版注册** → 「本机机器码」，点一下可全选
- 或让客户运行诊断（不开界面）：

```bat
XingLianCast.exe --diag
```

输出机器码、授权状态、今日试用剩余；同时写到 `%TEMP%\xl_diag.txt`。

## 三、授权机制

| 项 | 说明 |
|---|---|
| 算法 | ECDSA P-256 签名，客户端只内置公钥（无法伪造） |
| 绑定 | 机器码（机器名 + 系统盘卷信息 + CPU 核数 → SHA256 前 6 字节） |
| 码格式 | `XL1.<base64url(payload 12B + 签名 64B)>`，共 106 字符 |
| 载荷 | 版本 1B + 机器码摘要 6B + 到期天数 4B（`FFFFFFFF`=永久）+ 功能位 1B |
| 试用 | 未注册每天 300 秒；**引擎自己记账**（`engine_trial.dat`），改界面绕不过 |
| 校验位置 | **引擎**（`XingLianCastSender.exe`）：验签失败或试用用尽 → 拒绝推流，退出码 3 |

## 四、常见问题

| 客户反馈 | 原因 | 处理 |
|---|---|---|
| 「激活码与本机机器码不匹配」 | 换机器/重装系统 | 重新发码 |
| 「激活码无效（签名校验失败）」 | 复制漏字符/换行 | 让客户整段重新复制 |
| 「激活码已过期」 | 发的是限时码 | 续期 |
| 注册成功但重启又变未注册 | 写盘被安全软件拦 | 程序会换位置保存；仍失败则手动以管理员运行一次 |
| 客户想换电脑 | — | 按新机器码重新发码（旧码在新机上无效） |

## 五、密钥与备份

| 文件 | 用途 |
|---|---|
| `signing\license-private.txt` | 授权签发私钥（X/Y/D） |
| `installer\tools\license-private.txt` | 同上（工作副本） |
| `signing\xinglian-codesign.pfx` | 代码签名证书（密码 `XingLian!2026`） |
| `signing\xinglian-codesign.cer` | 公钥证书（随安装包分发，供客户端信任发布者） |

**离线备份**（务必保存到 U 盘/加密网盘）：

```
XingLianCast-signing-backup-<日期>.7z     AES-256 + 文件名加密，密码 XingLian!2026
```

内含授权私钥、代码签名 PFX/CER、发码工具。

> 私钥丢失 → 以后**发不出新激活码**（已发出的码仍有效）。
> 证书丢失 → 无法再给新版本签名（已安装用户不受影响）。
