# 常见问题

## 搜不到电视

1. 确认电视端 App **正在前台运行**（退到后台就不广播了）
2. 确认电脑和电视在**同一个网段**（例如都是 192.168.1.x）
3. 关闭路由器的「AP 隔离 / 客户端隔离」
4. 电脑防火墙放行 UDP 45691

## 画面卡顿

| 现象 | 原因 | 处理 |
|---|---|---|
| 编码耗时/帧 > 16ms | 电脑编码跟不上 | 分辨率降到 1080p 或 720p |
| 电视丢包/秒 持续增长 | 电视解码跟不上 | 降分辨率，或打开「流畅优先」 |
| 网络延迟 > 50ms | 网络拥塞 / 干扰 | 电视改用有线，或换 5GHz Wi-Fi |
| 采集卡顿 很多 | 电脑 GPU 被其它程序占满 | 关掉占 GPU 的程序 |

## 电视黑屏 / 一片绿

1. 停掉投屏，把电视端 App **完全退出**再重新打开
2. 重新点「开始投屏」
3. 仍不行：降分辨率到 720p 再试

## 电视没有声音

1. 界面「传输声音」是否为**开**（绿色）
2. 电脑系统音量是否静音
3. 电视音量是否静音、输入源是否正确

## 画面静止后电视显示“已断开”

v1.0.46 起已修复（静止时电脑会持续补发最后一帧）。
如仍出现，请确认版本 ≥ 1.0.46。

## 提示“电视被占用”

同一台电视同时只接受一台电脑投屏（先连的优先）。等对方停止，或让对方点「停止投屏」。

## 提示“电视端已断开”

- 电视端 App 被关闭 / 电视关机 / 电视换 IP
- 打开「自动恢复」后，电视恢复时会自动重连

## 杀毒软件拦截

本软件只监听 UDP、不访问外网。若被拦截，请把
`C:\Program Files\XingLianCast\XingLianCastSender.exe` 加入白名单。
