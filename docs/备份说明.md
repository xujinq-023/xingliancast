## 三、离线私钥（唯一不可再生）

```
XingLianCast-signing-backup-YYYYMMDD.7z     AES-256 + 文件名加密
密码：XingLian!2026（单独记，不要和压缩包放一起）
```

内含：
- `license-private.txt` —— **授权签发私钥**（丢了就发不出新激活码）
- `xinglian-codesign.pfx/.cer` —— 代码签名证书（丢了无法给新版本签名）
- `MakeLicense.exe` / `MakeLicenseGui.exe` —— 发码工具

存放建议：U 盘 ×1 + 加密网盘 ×1，两处都要有。

## 四、恢复流程

### 只想继续开发

```bat
git clone git@github.com:xujinq-023/XingLianCast.git
```

然后按 `docs/开发指南.md` 配环境、构建。

### 要重新能发码

1. 解压离线 7z，取出 `license-private.txt` → 放回 `installer\tools\`
2. 取出 `xinglian-codesign.pfx` → 导入 `Cert:\CurrentUser\My`
3. 验证：`MakeLicense.exe /machine <你的机器码> /days 0` 应能出码

### 要重新签名

```powershell
$c = Get-Item 'Cert:\CurrentUser\My\<新指纹>'
Set-AuthenticodeSignature -FilePath <exe> -Certificate $c
```
并更新 `sender-pc\ui\obf.bat` 里的指纹。
