## 三、离线私钥（唯一不可再生）

```
XingLianCast-signing-backup-YYYYMMDD.7z     AES-256 + 文件名加密
密码：XingLian!2026（单独记，不要和压缩包放一起）
```

内含：
- `license-private.txt` —— **授权签发私钥**（丢了就发不出新激活码）
- `xinglian-codesign.pfx/.cer` —— 代码签名证书（丢了无法给新版本签名）
- `MakeLicense.exe` / `MakeLicenseGui.exe` —— 发码工具

存放建议：U 盘 ×1 + 加密网盘 ×1，两处都要有。

## 四、恢复流程

### 只想继续开发

```bat
git clone git@github.com:xujinq-023/XingLianCast.git
```

然后按 `docs/开发指南.md` 配环境、构建。

### 要重新能发码

1. 解压离线 7z，取出 `license-private.txt` → 放回 `installer\tools\`
2. 取出 `xinglian-codesign.pfx` → 导入 `Cert:\CurrentUser\My`
3. 验证：`MakeLicense.exe /machine <你的机器码> /days 0` 应能出码

### 要重新签名

```powershell
$c = Get-Item 'Cert:\CurrentUser\My\<新指纹>'
Set-AuthenticodeSignature -FilePath <exe> -Certificate $c
```
并更新 `sender-pc\ui\obf.bat` 里的指纹。

## 五、快照命名与当前版本

NAS 上按 `YYYY-MM-DD-vX.Y.Z` 建目录，每次发布一个新目录（不覆盖旧的，便于回滚）：

```
\\10.5.9.6\Images and Software\XingLianCast\
  2026-11-14\              首个快照（1.0.1 时代，产物带 Low 标签，不可对外分发）
  2026-11-14-v1.0.1\        同上
  2026-11-14-v1.0.4\        修复安装包完整性标签
  2026-11-14-v1.0.5\        修复「第二台电脑连入时画面中断」
  2026-11-14-v1.0.6\        会话活跃判定加强
  2026-11-14-v1.0.8\        修复提示条超时切回等待页
  2026-11-14-v1.0.9\        区分「已停止投屏」与「已拒绝」文案
  2026-11-14-v1.0.12\       ★ 当前版本（电脑端/电视端统一 1.0.12）
```

每个快照包含：

| 子目录 | 内容 |
|---|---|
| `source\` | `git archive HEAD` 解出的源码 |
| `dist\` | 安装包 / 便携版 / APK / 证书 / 安装说明 / 诊断工具（**完整性标签已修正**） |
| `build\` | 已构建的 exe 与 APK |
| `signing-backup\` | 私钥加密包（AES-256） |
| `备份说明.txt` | 该版本改了什么 |

> **上传前必须做的事**：`dist\` 里的文件要先过 `tools\fix-integrity-labels.ps1`，
> 否则从 NAS 取回的文件会带 `Low Mandatory Level` 标签，客户机装不上。
> 1.0.4 之前的两份快照就是这个问题，**不要对外分发**。
