# 安装说明

## Windows 电脑端

### 安装包（推荐）

- 文件名：`XingLianCast-Setup-x.y.z.exe`
- 需要管理员权限：安装到 `C:\Program Files\XingLianCast` 并添加入站防火墙规则
- 卸载：Windows「应用和功能」里卸载「星联投屏」

### 便携版

- 文件名：`XingLianCast-Portable-x.y.z.zip`
- 解压到任意目录，运行 `XingLianCast.exe`（不含开机自启与卸载项）
- 配置与日志在 `%LOCALAPPDATA%\星联投屏\`

### 防火墙

程序会自动放行以下入站 UDP 端口：

| 端口 | 用途 |
|---|---|
| 45690 | 视频 / 音频 / 控制数据 |
| 45691 | 设备发现广播 |
| 45692 | 电视端状态回传 |

如被安全策略拦截，请手动放行这三个 UDP 端口。

## 电视端

### 前提

- Android 7.0（API 24）及以上
- 允许安装未知来源应用

### 三种安装方式

**1. U 盘**
1. 把 `receiver-tv.apk` 拷到 U 盘根目录
2. U 盘插到电视，打开电视自带的「文件管理」
3. 选中 APK → 安装

**2. adb（同一局域网）**

```bash
adb connect 192.168.1.50:5555
adb install -r receiver-tv.apk
```

**3. 电视应用市场助手**

在「当贝市场」「沙发管家」中选择「本地安装」，指向 U 盘里的 APK。

### 说明

- 电视端**没有**开机自启，每次投屏前需手动打开并保持在前台
- 电视端不联网、不收集任何数据

## 卸载

- 电脑：控制面板卸载，或直接删除便携版目录
- 电视：电视「设置 → 应用」里卸载「星联投屏」
