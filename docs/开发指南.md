## 二、构建

### 电脑端引擎（C++）

```bat
call "D:\Dev\VS2022BuildTools\VC\Auxiliary\Build\vcvars64.bat"
cd sender-pc\build
cmake -S .. -B . -G "NMake Makefiles" -DCMAKE_BUILD_TYPE=Release
nmake
```

产物：`sender-pc\build\XingLianCastSender.exe`
（`CMakeLists.txt` 里用 `OUTPUT_NAME XingLianCastSender`，**改生成器后必须重新 configure**）

### 电脑端界面（C#）

```bat
cd sender-pc\ui
obf.bat        :: 编译 → ConfuserEx 混淆 → Authenticode 签名
```

产物：`sender-pc\ui\XingLianCast.exe`
只编译不混淆：`build_ui.bat`

### 电视端（Java）

```bat
cd receiver-tv
powershell -ExecutionPolicy Bypass -File build.ps1
```

产物：`receiver-tv\out\receiver-tv-debug.apk`
（aapt2 compile/link → javac → d8 → 注入 dex → zipalign → apksigner）

## 三、签名

- 证书：自签名 `CN=XingLianCast`，指纹 `C298644FCF4FDBE22B49BA99472A4E50AC217E27`
- 私钥：`signing\xinglian-codesign.pfx`（密码 `XingLian!2026`）
- **顺序：先混淆，后签名**（混淆会改动 IL，签名会失效）

```powershell
$c = Get-Item 'Cert:\CurrentUser\My\C298644FCF4FDBE22B49BA99472A4E50AC217E27'
Set-AuthenticodeSignature -FilePath <exe> -Certificate $c
```

本机已导入 `LocalMachine\Root` + `TrustedPublisher`；客户机由安装程序自动导入。

## 四、打包

```bat
:: 1. 更新 payload（必须先在 build/ui/out 里生成新产物）
installer\make_payload.bat

:: 2. 安装程序（内嵌 payload.zip + 图标）
csc /target:winexe /out:XingLianSetup.exe ^
    /resource:payload.zip,payload.zip /resource:..\payload\logo.ico,app.ico ^
    /win32icon:..\payload\logo.ico Setup.cs SetupInfo.cs

:: 3. 便携版
7z a -tzip -mx=9 ..\dist\XingLianCast-Portable-1.0.0.zip ..\payload\*
```

产物目录：`installer\dist\`

## 六、协议要点

```
每包 16 字节大端头：magic(2) type(1) flags(1) seq(4) ts(4) len(2) crc(2)
type: 0=VIDEO 1=AUDIO 2=PKT_META 3=CTRL
CTRL: "hi" 开始 / "bye" 结束 / "ka" 心跳 / "p<ms>" ping / "hn<名字>\t<端口>"
      "lk" 锁屏 / "ul" 解锁 / "sw" 显示器回退
```

- 电视 → 电脑反馈：UDP **45692**（`PJS/F1` 帧，含 fps/lost/drop/idr/aud/res，`q<ms>` 为 pong）
- 电视 → 广播发现：UDP **45691**，每秒一次
- 视频流：电脑 → 电视 UDP **45690**

详见 `docs/architecture.md`。

## 七、调试开关

| 环境变量 / 参数 | 作用 |
|---|---|
| `--ip <IP>` `--port <P>` | 直接指定电视，跳过发现 |
| `--display N` | 选择显示器 |
| `--height 1080` | 限制输出高度 |
| `--sw` | 强制软件编码 |
| `--machinecode` / `--machinedbg` | 打印机器码 / 原始串 |
| `--license <code>` | 注入授权码 |
| `PJS_TEXTURE=1` | 编码输入走 GPU 纹理 |
| `PJS_NOENC=1` | 不编码（只验证采集） |
| `PJS_NOSEND=1` | 不发送（只验证编码） |
| `PJS_FORCE_PAUSE=1` | 模拟锁屏 4 秒后恢复 |
| `PJS_FAKE_LOCK=1` | 模拟锁屏 3 秒 |
| `PJS_SLOWLOG=1` | 每帧日志 |
| `XingLianCast.exe --diag [code]` | 机器码 / 授权状态 / 试用剩余 / 校验激活码 |
| `XingLianCast.exe --register <code>` | 命令行注册 |
| `XingLianCast.exe --about` / `--license-ui` | 直接打开对应窗口 |
