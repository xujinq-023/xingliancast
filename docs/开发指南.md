## 二、构建

### 电脑端引擎（C++）

```bat
call "D:\Dev\VS2022BuildTools\VC\Auxiliary\Build\vcvars64.bat"
cd sender-pc\build
cmake -S .. -B . -G "NMake Makefiles" -DCMAKE_BUILD_TYPE=Release
nmake
```

产物：`sender-pc\build\XingLianCastSender.exe`
（`CMakeLists.txt` 里用 `OUTPUT_NAME XingLianCastSender`，**改生成器后必须重新 configure**）

```bat
cd sender-pc\ui
obf.bat        :: 编译 → ConfuserEx 混淆 → Authenticode 签名
```

产物：`sender-pc\ui\XingLianCast.exe`
只编译不混淆：`build_ui.bat`

### 电视端（Java）

```bat
cd receiver-tv
powershell -ExecutionPolicy Bypass -File build.ps1
```

产物：`receiver-tv\out\receiver-tv-debug.apk`
（aapt2 compile/link → javac → d8 → 注入 dex → zipalign → apksigner）

### 4.1 发布前必做：清除「低完整性」标签

如果产物是在受限/沙箱目录里生成的，文件会带上 `Low Mandatory Level` 标签，
客户机双击时会以**低完整性**运行、任何目录都写不进去（表现为"无法写入任何候选目录"，
且右键以管理员身份运行也无效）。

```powershell
powershell -ExecutionPolicy Bypass -File tools\fix-integrity-labels.ps1 "installer\dist"
```

脚本会重置 ACL 继承并设为 `Medium`，同时逐个打印校验结果。
**预期全部显示 `Medium Mandatory Level`。**

## 五、调试与日志

### 5.1 电脑端

```
%LOCALAPPDATA%\星联投屏\logs\XingLianCast.log
```

每秒一行统计：

```
fps= 收= 限= 间隔max= 大间隔= 显示间隔max= 包= 音包= 流量= 转换= 编码= 送失= [GPU转换] tvfps= tvlost= tvdrop= rtt=
```

### 5.2 电视端（无需 root）

```bash
adb pull /sdcard/Android/data/tv.projector.receiver/files/logs/receiver.log
```

日志包含：

| 关键字 | 含义 |
|---|---|
| `accept new peer <ip>` | 接受了某台电脑的会话 |
| `busy-refuse <ip> (peer=… rxWall=… frameWall=…)` | 已有会话，拒绝了后来者（每 1.5 秒最多一条） |
| `ignore bye from non-owner <ip>` | 忽略了非当前会话发来的 bye（防止被拒者退出时打断画面） |
| `hello -> reset codec + wait IDR` | 收到 hello 并重建解码器（仅会话空闲时允许） |
| `hello ignored (session active…)` | 画面正常时忽略别的电脑的 hello |
| `stat fps=… fed=… lost=… dropAu=… res=…` | 每 5 秒一次的解码统计 |
| `FATAL in <thread>: …` | 未捕获异常堆栈（崩溃排查） |

### 5.3 常用诊断开关

| 开关 | 作用 |
|---|---|
| `XingLianCast.exe --diag` | 打印环境、编码器、网络自检 |
| `XingLianCast.exe --machinecode` | 打印机器码（发码用） |
| `XingLianCast.exe --license-ui` | 打开注册窗口 |
| `XingLianCast.exe --register <key>` | 命令行注册 |
| `PJS_IGNOREBUSY=1` + 引擎 | 测试用：忽略电视返回的 busy（模拟第二客户端时防止把自己停掉） |
| `XingLianCast-Setup-*.exe --tokeninfo` | 打印安装程序进程身份/完整性（排查权限问题） |

### 5.4 投屏会话规则（改动时务必保留）

1. **先连优先**：已有电脑在投屏（5 秒内收过包，或 3 秒内解出过帧）时，其它 IP 的包一律丢弃并回 `PJS/B1 busy=1`
2. **拒绝包不在接收线程发送**：给陌生 IP 发包会触发 ARP 解析、阻塞数百毫秒，必须走独立线程 + 独立 socket
3. **hello 不打断画面**：最近 2 秒还在出帧时不重建解码器，否则当前流要等下一个 IDR（约 1 秒黑屏）
4. **只认当前会话的 bye/lk/ul/sw**：被拒绝的电脑退出时也会发 bye，绝不能清掉正在投屏的会话
5. **提示条超时只隐藏提示条**：不能调用 `showIdle()`，否则画面会被切回"等待电脑投屏"页

## 六、协议要点

```
每包 16 字节大端头：magic(2) type(1) flags(1) seq(4) ts(4) len(2) crc(2)
type: 0=VIDEO 1=AUDIO 2=PKT_META 3=CTRL
CTRL: "hi" 开始 / "bye" 结束 / "ka" 心跳 / "p<ms>" ping / "hn<名字>\t<端口>"
      "lk" 锁屏 / "ul" 解锁 / "sw" 显示器回退
```

- 电视 → 电脑反馈：UDP **45692**（`PJS/F1` 帧，含 fps/lost/drop/idr/aud/res，`q<ms>` 为 pong）
- 电视 → 广播发现：UDP **45691**，每秒一次
- 视频流：电脑 → 电视 UDP **45690**

详见 `docs/architecture.md`。

### 5.5 机器码口径（改动时务必三端同步）

机器码 = SHA256(`机器名|系统盘卷标:系统盘总容量|逻辑核数`) 前 6 字节 → `XXXX-XXXX-XXXX`。

三处实现必须逐字节一致，否则会出现「注册成功但仍不能投屏」：

| 端 | 位置 | 注意 |
|---|---|---|
| 引擎 | `sender-pc\src\license.h` `machine_raw()` | 系统盘用 `GetSystemDirectoryW` 取盘符（**不要硬编码 C:**）；卷标/机器名用**宽字符 API + UTF-8**（ANSI 会得到 GBK，和 C# 对不上）；卷标不截断 |
| 界面 | `sender-pc\ui\ProjectorUi.cs` `License.MachineCode()` | `DriveInfo(Path.GetPathRoot(Environment.SystemDirectory))` + UTF-8 |
| 发码 | `installer\tools\MakeLicense.cs` `LocalMachineCode()` | 同上；CLI 会归一机器码（补横线/大写） |

改完用 `XingLianCastSender.exe --machinecode` 与界面显示的机器码对比，必须完全相同。
