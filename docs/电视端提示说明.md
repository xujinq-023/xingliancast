# 电视端提示含义

电视端在投屏过程中会显示不同的状态文案，含义如下：

| 提示 | 含义 | 需要做什么 |
|---|---|---|
| **等待电脑投屏…** | 空闲，电视在等电脑连接 | 在电脑端点「开始投屏」 |
| **正在连接…** | 已收到电脑握手，正在等第一帧画面 | 等 1~2 秒；长期停在这里说明网络/编码异常 |
| **电脑已锁屏** | 电脑锁屏，画面已隐藏保护隐私 | 解锁电脑，会自动恢复 |
| **电脑端已停止投屏** | 电脑端主动点了「停止投屏」 | 想继续就再点「开始投屏」 |
| **连接已断开，等待重连…** | 电脑端异常掉线（关机/断网/崩溃） | 检查网络，电脑端重新投屏 |
| **另一台电脑尝试投屏，已拒绝** | 已有电脑在投屏，后连的被拒绝（先连优先） | 等当前电脑停止后再试 |
| **画面已暂停（电脑可能已锁屏）** | 心跳还在但 3 秒没有画面 | 通常是锁屏/采集暂停，解锁即可 |

页面上的设备信息：

```
TV  →  QINL-370A   10.5.9.22:45690        ← 电视型号 / IP / 端口
PC  →  DESKTOP-HARVEY   10.5.9.11:55484   ← 电脑名 / IP / 端口
```

## 遥控器操作

| 按键 | 作用 |
|---|---|
| **返回键** | 退出接收端 |
| **MENU 键** | 切换右上角信息条（分辨率、帧率、设备信息） |
| **长按 OK / 确认键** | 开启/关闭文件日志（排查问题时用） |

## 关于帧率

投屏中的 `fps` 是**电视端实际解码并显示的帧率**。

- 桌面**静止**时通常会显示 **约 2fps**：DXGI 桌面复制只在画面变化时产出帧，
  电脑端仅按“静止画面每 2 秒补一个关键帧”维持连接，这是**省流量的正常行为**
- 画面一动（鼠标、视频、滚动）立即回到 60fps

## 常见提示组合

| 场景 | 电视显示 |
|---|---|
| 电脑端正常停止 | 「电脑端已停止投屏」→ 3 秒后回等待页 |
| 电脑端直接关机/断网 | 「连接已断开，等待重连…」→ 10 秒后回等待页 |
| 电脑锁屏 | 「电脑已锁屏」，解锁后自动恢复 |
| 第二台电脑连入 | 「另一台电脑尝试投屏，已拒绝」，当前画面不受影响 |

## 排查问题时

电视端日志文件（无需 root，可用 adb 拉取）：

```bash
adb pull /sdcard/Android/data/tv.projector.receiver/files/logs/receiver.log
```

日志包含：`accept new peer` / `busy-refuse` / `ignore bye from non-owner` /
`hello -> reset` / 每秒 `stat fps=… fed=… lost=…` / 崩溃堆栈（`FATAL`）。
把这份日志和电脑端 `%LOCALAPPDATA%\星联投屏\logs\XingLianCast.log` 一起发给我们即可定位。
