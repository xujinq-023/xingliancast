# 使用手册

## 界面一览

```
显示器  [选择要投的屏幕]
分辨率  [原生 / 1440p / 1080p / 720p]
码率    [4000 ~ 20000 kbps]
日志上限 [5 ~ 100 MB]
接收端  [自动发现电视，无需手动填 IP]
帧率    [60 / 45 / 30]
[开始投屏] [停止投屏] [传输声音] [自动恢复] [流畅优先]
[10 个实时监控指标]
```

## 各项设置

### 显示器
要投屏的物理屏幕。多显示器时按「显示器 1 / 2 …」选择。

### 分辨率
- **原生分辨率**：不动，最清晰也最吃性能
- **1080p**：推荐值，绝大多数场景最平衡
- **720p**：老电视 / 弱网兜底

> 2560×1440@60 对多数电视偏重；1080p 通常更流畅。

### 码率
- 8000 kbps：默认，1080p 清晰足够
- 12000~20000 kbps：高动态画面（视频、游戏）更清晰
- 4000 kbps：网络较差时使用

> 码率不影响流畅度上限；流畅度主要看分辨率与电视解码能力。

### 帧率
| 选项 | 适用 |
|---|---|
| **60** | 桌面操作、拖动窗口、游戏（默认） |
| **45** | 折中 |
| **30** | 视频 / 监控，60Hz 屏上节奏最匀 |

**投屏过程中改帧率会立即生效**（约 1 秒），不需要重新开始投屏。

### 接收端
自动发现同一局域网的电视：
- 有电视 → 显示 `型号 · IP`
- 没有 → 红色提示「未发现电视端，请确认已开启」，下拉框同时被禁用

多台电视时点名称即可切换。

### 传输声音
- 默认**关闭**
- 打开后把电脑播放的声音一并投到电视（AAC 128kbps）
- 投屏中可随时开关，立即生效

### 自动恢复
- 打开：电视端断开（App 退出、换 IP、断网）后自动重连
- 关闭：断开后停止投屏，等待手动开始

### 流畅优先
- 默认**关闭**（保持最高清晰度）
- 打开后：电视解码跟不上时自动降帧（60→30→24），丢包时自动降码率
- 适用于老电视、监控画面等解码压力大的场景

## 监控指标怎么读

| 指标 | 含义 | 正常值 |
|---|---|---|
| 电脑帧率 | 电脑端实际编码帧率 | 接近设定帧率 |
| 编码耗时/帧 | 单帧编码耗时 | < 10 ms |
| 音频带宽 | 声音码率（关闭时为 0） | 约 128 kbps |
| 实时流量 | 当前发送带宽 | 接近设定码率 |
| 电脑丢包/秒 | UDP 发送失败次数 | 0 |
| 电视帧率 | 电视端实际渲染帧率 | 应接近电脑帧率 |
| 采集卡顿 | 抓屏帧间隔 >25ms 的次数 | 个位数 |
| 限帧丢弃 | 限流器主动丢弃的帧 | 0 |
| 网络延迟 | 端到端往返时延 | 1~10 ms |
| 总发送流量 | 本次运行累计发送量 | 持续增长 |

排查顺序：

1. **编码耗时 > 16ms** → 降分辨率
2. **电视丢包/秒 持续增长** → 电视解码不过来或网络拥塞
3. **网络延迟 > 50ms** → 网络问题（Wi-Fi 干扰、交换机）
4. **采集卡顿很多** → 电脑 GPU 被其它程序占用

## 推荐配置

| 场景 | 建议 |
|---|---|
| 办公演示 / PPT | 1080p、8000、60fps |
| 看视频（含 4K） | 1080p、12000、30 或 60fps |
| 看监控（萤石云等） | 1080p、8000、30fps，必要时开「流畅优先」 |
| 游戏 | 1080p、12000~20000、60fps |
| 网络较差 | 720p、4000、30fps |
