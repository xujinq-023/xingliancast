# 快速开始（3 步）

## 第 1 步：安装电脑端

1. 到 [下载页](https://github.com/xujinq-023/xingliancast/releases/latest) 下载 `XingLianCast-Setup-x.y.z.exe`
2. 双击安装（需要管理员权限，用于放行防火墙）
3. 安装完成后从桌面或开始菜单打开「星联投屏」

> 也可以下载便携版 `Portable-x.y.z.zip`，解压后直接运行 `XingLianCast.exe`。

## 第 2 步：安装电视端

把 `receiver-tv.apk` 装到电视上（任选一种）：

| 方式 | 步骤 |
|---|---|
| **U 盘**（最简单） | 把 APK 拷到 U 盘 → 插电视 → 用电视的文件管理器打开安装 |
| **adb** | `adb connect 电视IP:5555` → `adb install -r receiver-tv.apk` |
| **电视助手** | 用「当贝市场 / 沙发管家」的本地安装功能 |

> 电视一般需要先到「设置 → 安全 → 未知来源」允许安装外部应用。

## 第 3 步：连接

1. 确认电脑和电视连在**同一个局域网**
2. 电视上打开「星联投屏」，看到「等待电脑投屏…」
3. 电脑端界面「接收端」会自动出现电视名称，点 **开始投屏**

正常 1~3 秒内电视就会出现画面。
